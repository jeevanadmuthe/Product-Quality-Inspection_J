3. STEP 1: PRODUCT CATALOG MANAGEMENT (/products)
================================================================================
Navigation: Click "Products" in the top navigation bar.
URL: http://127.0.0.1:5000/products

WORKFLOW:
  1. Review existing catalog products (e.g., "Precision Cast Rotor Flange").
  2. To register a new manufactured part:
     - Locate the "Register Manufactured Part" form on the left.
     - Part Name: Enter the name (e.g., "Cylinder Block Casting - High Duty").
     - Specification Category: Default is "Metal casting" (or customize).
     - Click "Register Product".
  3. The product is immediately available in the batch creation dropdown.

================================================================================
4. STEP 2: PRODUCTION BATCH CREATION & MANAGEMENT (/batches)
================================================================================
Navigation: Click "Batches" in the top navigation bar.
URL: http://127.0.0.1:5000/batches

WORKFLOW:
  1. Locate the "Register Production Batch" form on the left panel:
     - Batch Code / Lot Identifier: Enter a unique identifier (e.g., B-105).
     - Product Specification: Select the product from the dropdown.
     - Lot Quantity: Enter total manufactured units (e.g., 50 or 100).
     - Production Date: Pick the date of the production run.
     - Click "Create Production Batch".
  2. In the "Active Batch Inventory" table on the right:
     - Check the new batch row showing:
       * Batch Code, Part Name, Lot Size, Inspected Sample Count.
       * Defect count badge (e.g., "1 defect").
       * Current Status: "Open", "On hold", or "Released".
  3. Click the sample count link (e.g., "0 inspected") to view or filter
     inspections for that specific batch.

================================================================================
5. STEP 3: REGISTERING VISUAL INSPECTIONS & AI CNN SCREENING (/inspections)
================================================================================
Navigation: Click "Inspections" in the top navigation bar.
URL: http://127.0.0.1:5000/inspections

WORKFLOW:
  1. Filter / Search Existing Records:
     - Use the top search bar to filter by sample ref, batch code, or product.
     - Use quick status filter tabs: "All", "Needs Review", "Defective", "Good".
  2. Register a New Sample (Left Form "Register Sample Inspection #QC-01"):
     - Production Batch: Select the batch (e.g., B-104 or B-105).
     - Sample Reference: Enter sample ID (e.g., ITEM-001 or LOT-104-SMP03).
     - Image Perspective: Choose "Item", "Surface", or "Batch sample".
     - Visual Observation Notes: Enter notes (e.g., "Visual inspection of top
       rim and bore; checked for porosity and hairline shrinkage").
     - Optical Capture Image: Click "Choose File" and upload a casting image
       (.jpg, .png, .webp).
     - Click "Submit Sample for CNN Screening".
  3. Automatic Pipeline Execution:
     - The PyTorch CNN model processes the image in ~12 to 45 milliseconds.
     - Performs Test-Time Augmentation (TTA) and outputs class probabilities.
     - Backpropagates through convolutional layer 4_2 to compute Grad-CAM
       Class Activation defect localization.
     - Stores the raw optical image in uploads/user_images/ and the Grad-CAM
       heatmap in uploads/aiml/.
     - Automatically redirects you to the newly created Inspection Record page.

================================================================================
6. STEP 4: DUAL-LENS EVIDENCE ANALYSIS & HUMAN DISPOSITION (/inspections/<id>)
================================================================================
URL: http://127.0.0.1:5000/inspections/<id>

WORKFLOW:
  1. Examine the Dual-Lens Evidence Viewer:
     - Left Pane (Optical Sensor Capture): Full-resolution original photo.
     - Right Pane (Grad-CAM Defect Localization): Visual heatmap showing the
       precise structural hotspot (red/amber) where defects were recognized.
     - Inspector Observation Notes: Context logged during upload.
  2. Inspect the CNN Machine Vision Diagnostic Panel:
     - Classification Result:
       * "Passed (Non-Defective)" (Green badge) OR
       * "Defect Anomaly Detected" (Red badge)
     - Calibrated Confidence Score: e.g., 99.8%.
     - Inference Latency: Sub-50ms execution speed.
     - Backbone architecture and model version manifest.
  3. Human Quality Review Disposition (Requires Supervisor or Manager login):
     - If logged in as Inspector, switch or sign in as supervisor or manager.
     - Select Quality Decision:
       * "Good — Release to next operation" (Passes item)
       * "Defective — Segregate and quarantine" (Rejects item)
       * "Uncertain — Require metrology / CMM lab check"
     - Enter Disposition Notes / Audit Reason (e.g., "Confirmed porosity defect
       on flange bore matching Grad-CAM hotspot").
     - Click "Save Quality Disposition".
     - The status immediately updates from "Pending review" to "Reviewed".

7. STEP 5: ASSIGNING & TRACKING CORRECTIVE ACTIONS - CAPA (/actions)
================================================================================
When a defect is detected or process deviation occurs:

WORKFLOW:
  1. Assign Action from Inspection Record (/inspections/<id>):
     - Scroll to the bottom section: "Linked Corrective Actions (CAPA)".
     - (Requires Supervisor or Manager role).
     - Form Fields:
       * Action Title: e.g., "Re-machine sealing face and verify mold venting".
       * Assigned Owner: e.g., "Sarah Tooling" or "Line 3 Maintenance".
       * Due Date: Select target resolution date.
       * Action Notes / Containment Steps: e.g., "Quarantine adjacent 10 units".
     - Click "Assign Corrective Action".
  2. Manage Central CAPA Registry:
     - Click "Actions" in the navbar -> http://127.0.0.1:5000/actions
     - Review all active corrective actions across the facility.
     - Filter/inspect owner, due date, sample reference, and status.
     - To update progress (Supervisor or Manager):
       * Use the "Update" form dropdown on any action card.
       * Change status: "Open" -> "In progress" -> "Completed" (or "Reopened").
       * Enter an update log message (appended with author timestamp).
       * Click "Update Status".

8. STEP 6: BATCH RELEASE / HOLD FINAL DECISION (/batches)
================================================================================
Navigation: Click "Batches" in the top navigation bar.
URL: http://127.0.0.1:5000/batches
Role Required: Plant Quality Manager ("manager" / "manager123").

WORKFLOW:
  1. Once all sample inspections and CAPA actions for a batch are completed:
  2. Locate the batch row in the Active Batch Inventory.
  3. Click the "Decide ▾" dropdown button under the ACTIONS column.
  4. Select New Disposition:
     - "Released" -> If all samples passed defect tolerances; authorized for
       downstream assembly or customer shipment.
     - "Hold" -> If unresolved defects or active CAPA require quarantine.
     - "Open" -> If production or testing is still underway.
  5. Mandatory Reason Note: Enter an auditable reason (e.g., "All 5 samples
     cleared visual & CMM dimensional checks. Approved for delivery.").
  6. Click "Confirm".
  7. The batch badge updates immediately to "Released" (green) or "On hold" (amber).

11. STEP 9: INTERACTIVE CNN MODEL & REAL-TIME SCREENER (/model)
================================================================================
Navigation: Click "CNN Model" in the top navigation bar.
URL: http://127.0.0.1:5000/model-architecture (or /model)

WORKFLOW:
  1. Architecture & Performance Review:
     - Review the 4-stage convolutional neural network specification:
       * Stage 1: Specular boundary & edge feature filters.
       * Stage 2: Metallic grain texture & circular porosity filters.
       * Stage 3 & 4: Macro structural anomaly synthesis (blowholes, cracks).
       * Grad-CAM Engine: Backward activation localization via conv4_2 layer.
     - Check held-out test set accuracy (99.86%), precision, recall, and F1 score.
     - Review the confusion matrix comparing Deep CNN against classical SVM.
  2. Interactive Real-Time Screening Sandbox:
     - Scroll to the "Interactive Real-Time CNN Screening" widget.
     - Drag and drop or browse ANY casting image directly into the sandbox.
     - Sub-50ms instant classification occurs without saving to the database.
     - View the live side-by-side original image and Grad-CAM defect heatmap.
     - Ideal for rapid bench testing or live product demonstrations.
